# Methodology

This project follows a structured analytics workflow:

1. Business Understanding  
2. Data Understanding  
3. Data Cleaning  
4. Exploratory Data Analysis  
5. Insight Generation  
6. Preparation for Dashboard Visualization  

The objective of using this workflow was to keep the project focused, interpretable, and aligned with professional analytics practice.

The analysis intentionally prioritized:
- clarity
- reproducibility
- business readability
- cautious interpretation of unreliable variables
