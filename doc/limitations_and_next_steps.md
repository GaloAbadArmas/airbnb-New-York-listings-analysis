# Limitations and Next Steps

## Limitations

This project has several dataset-related limitations that affect interpretation:

- price behavior appears unusually uniform across segments
- some original labels were inconsistent
- missing values were present in relevant variables
- some date values were not temporally valid
- the dataset may not fully reflect real market conditions

Because of these limitations, the strongest conclusions are restricted to descriptive patterns rather than deeper business recommendations.

---

## Next Steps

With a more reliable dataset available, future analysis could include:

- neighborhood-level segmentation
- more robust pricing analysis
- host-level patterns
- review recency analysis
- proxy analysis for occupancy or revenue potential

For this version of the project, the focus remained on building a transparent, well-structured, and portfolio-ready descriptive analysis.
