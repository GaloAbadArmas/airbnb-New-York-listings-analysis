# Portfolio Project Summary

This project was developed as an end-to-end data analytics case study focused on the Airbnb market in New York City.

The workflow included:

- data understanding
- data cleaning
- exploratory data analysis
- insight generation
- preparation for dashboard visualization

A major strength of the project is that it goes beyond descriptive analysis by including a data quality validation layer. During the analysis, several anomalies were identified, especially in price-related variables. Rather than ignoring these issues, the project documents them and adjusts the interpretation accordingly.

This case study demonstrates:

- structured analytical thinking
- practical data cleaning logic
- visual storytelling
- critical interpretation of imperfect data
- professional communication for portfolio presentation
